The boot ROM is not included: load the 32 KB interleaved image, or both 16 KB EPROM dumps at once (5053-1 = even bytes, 5053-2 = odd). It is kept in this browser only. Each workstation boots over the network as node 15 + its number (16, 17, …). To install: insert the ICON Fileserver Boot Diskette (4.01.00), add a hard disk, power on the fileserver and wait for Login:, then power on a workstation. Log in as root / superuser. Click a machine to give it the keyboard. Click a screen to use the mouse as the trackball (left/right button = the two ACTION keys; Esc releases). F11 / F12 = ACTION, Insert = HELP, Delete = RUBOUT, Scroll Lock = CURSOR LOCK, Home = CLR. The hard disk autosaves in this browser; disk changes apply at the next fileserver power-on. "New 64 MB" is a factory-formatted 1024×8×17 drive (two 32 MB partitions plus a small third); see docs/INSTALL.md.
