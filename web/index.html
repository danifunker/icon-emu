The boot ROM is not included: load the 32 KB interleaved image, or both 16 KB EPROM dumps at once (5053-1 = even bytes, 5053-2 = odd). It is kept in this browser only. Untick "Use the same ROM for all devices" to give the LEXICON and the ICONs different ROMs. Each workstation boots over the network as node 15 + its number (16, 17, …). Workstations with the Rel 2.11 boot ROM need ICON System Software 4.10.05 on the fileserver: the 4.10.01 workstation boot image crashes under that ROM. Install the 4.10.05 upgrade diskette with configure (see the rebuild guide, section 2b). The 5053 ISS 2 ROM works with either. Memory: 1 MB fits the CEMCORP "1 MEG ICON UPGRADE BOARD" to every machine at its next power-on. Only the Rel 2.11 ROM supports it (the 5053 ISS 2 ROM fails to network-boot, error 57); the kernel then reports about 969 KB. To install: insert the ICON Fileserver Boot Diskette (4.01.00), add a hard disk, power on the fileserver and wait for Login:, then power on a workstation. Log in as root / superuser. Click a machine to give it the keyboard. Click a screen to capture the keyboard and mouse: the mouse is the trackball and its buttons are the two ACTION keys. Press Ctrl+Alt to release (the browser also always releases on Esc). F11 / F12 = ACTION, Insert = HELP, Delete = RUBOUT, Scroll Lock = CURSOR LOCK, Home = CLR. The hard disk autosaves in this browser; disk changes apply at the next fileserver power-on. "New 64 MB" is a factory-formatted 1024×8×17 drive (two 32 MB partitions plus a small third); see the install notes.
