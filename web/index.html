Download and Upload work at any time. Edit adds Edit and Delete to each entry; deleting a folder deletes everything in it. The diskette can be changed at any time: the page takes it out, makes the change and puts it back, so don't change it while the ICON is writing to it. The hard disk can only be changed while every machine is off. Text is shown and saved with the ICON's accents (Telidon sequences) and line ends; ⟦ and ⟧ are its underline codes. Names are made to fit QNX (up to 16 letters, digits, _ . $).

Type text into the selected machine Paste lines below; each is typed into the machine you last clicked, followed by Enter, one line at a time. Only plain ASCII is typed. Useful for long commands, or for speech phrases made with scripts/lpc_encode.py --paste.

Getting started: load the boot ROM at the top of the page (it isn't included and stays in this browser). Add a hard disk, insert the ICON Fileserver Boot Diskette (4.01.00) and power on the fileserver. When it shows Login:, power on a workstation and log in as root / superuser. The rebuild guide takes you through the whole install.

Keyboard and mouse: click a machine to type on it. Click its screen to capture the mouse as the trackball; the mouse buttons are the two ACTION keys. Ctrl+Alt (or Esc) lets go. F11 / F12 = ACTION, Insert = HELP, Delete = RUBOUT, Scroll Lock = CURSOR LOCK, Home = CLR.

Files: open Files above to copy files between this computer and the diskette or hard disk. New blank inserts an empty, formatted 640K diskette. See moving files in and out.

Hard disk: saved in this browser automatically; download a copy after each step you care about. A new or loaded disk is used from the fileserver's next power-on.

Rel 2.11 ROM: its workstations need system software 4.10.05 on the fileserver (rebuild guide, section 3). The 1 MB memory option also needs this ROM.
